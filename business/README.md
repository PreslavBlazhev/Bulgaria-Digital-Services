# Бизнес материали

Работни файлове, които не са част от сайта.

| Файл / папка | Какво е |
|---|---|
| `marketing/marketing-checklist.txt` | Актуалният roadmap checklist — какво е готово и какво остава преди реклама |
| `marketing/BDS_Marketing_Performance_Tracker.xlsx` | Ad Performance / Dashboard / Pivot Analysis (колоната `Profit` да стане `Marketing Contribution`) |
| `google-ads/phases-12-13-import/` | CSV пакет за ръчен внос на ресторантската кампания — кампания, ad groups, ключови думи, RSA, активи, негативни думи |
| `domain/` | DMARC отчети от Google за bulgaria-digital-services.com |

Източникът на истината за рекламните текстове е `website/marketing/` —
CSV пакетът тук е експорт от него.
